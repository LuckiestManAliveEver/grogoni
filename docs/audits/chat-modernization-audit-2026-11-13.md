# Chat modernization audit: DeepSeek Chat Demo against Grogoni (2026-11-13)

Scope of this pass: the DeepSeek Chat Demo against Grogoni's chat, and the first capability built
from it (reply versions). The two earlier references were pinned but not audited in this pass; see
"Not done".

Every statement below is marked by how it was established:

- **Verified**: read in the source at the pinned commit, or shown by a test or a measurement.
- **Implemented**: changed in this commit, with tests.
- **Assumed**: not checked; treat as a question.
- **Deferred**: known, not built.

## Security review of the reference

Verified in source at `5d5dd754`:

- `src/services/settings.ts` keeps the provider API key in `localStorage`, and
  `src/services/api/client.ts` sends it from the browser. Not acceptable for a multi-tenant
  platform with platform-managed credentials. Nothing from these files is used.
- Four `dangerouslySetInnerHTML` sinks: `MathFormula.tsx` (two), `CodeBlock.tsx`,
  `MermaidDiagram.tsx`. Mermaid runs with `securityLevel: "strict"`. Any reuse needs its own
  review with model output treated as hostile.
- Links open with `rel="noreferrer"` and `target="_blank"`. No URL scheme allow-list was found in
  `Link.tsx` (Assumed: the mdast parser does not filter `javascript:`; check before reuse).
- Conversation history and attachments sit in one unscoped IndexedDB database: no account or
  tenant separation, no cleanup on sign-out.
